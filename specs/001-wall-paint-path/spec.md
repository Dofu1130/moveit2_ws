# Feature Specification: 牆面噴漆路徑規劃

**Feature Branch**: `001-wall-paint-path`
**Created**: 2026-03-05
**Status**: Draft
**Input**: User description: "Phase 1 - 機械手臂裝在四輪車上，左右平移，機械手臂填滿牆壁表面的路徑規劃"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 平面牆壁自動噴漆覆蓋 (Priority: P1)

操作員將搭載機械手臂的四輪車移動到牆壁前方，啟動噴漆任務後，系統自動規劃路徑讓機械手臂以掃描式（zig-zag）動作填滿整面牆壁。四輪車負責左右平移以擴展覆蓋範圍，機械手臂負責上下移動進行噴漆。

**Why this priority**: 這是整個噴漆機器人系統的核心功能，沒有路徑規劃就無法完成任何噴漆工作。

**Independent Test**: 在模擬環境中給定一面固定尺寸的牆壁，驗證機械手臂能產生完整覆蓋該牆面的運動軌跡。

**Acceptance Scenarios**:

1. **Given** 四輪車已定位於牆壁前方且牆壁尺寸已知, **When** 操作員啟動噴漆任務, **Then** 系統產生覆蓋整面牆壁的掃描路徑，且機械手臂按路徑執行動作
2. **Given** 牆壁寬度超過機械手臂的單次覆蓋範圍, **When** 機械手臂完成一個垂直條帶的噴漆, **Then** 四輪車自動左右平移至下一個條帶位置
3. **Given** 噴漆路徑已規劃完成, **When** 機械手臂執行路徑, **Then** 牆面覆蓋率達到 95% 以上，無明顯漏噴區域

---

### User Story 2 - 牆壁尺寸定義與任務設定 (Priority: P2)

操作員能夠手動輸入牆壁的寬度和高度，系統根據這些參數自動計算所需的路徑，包括四輪車需要平移的次數和機械手臂的掃描軌跡。

**Why this priority**: 操作員需要一個方式來告訴系統牆壁的大小，這是路徑規劃的前提條件。

**Independent Test**: 輸入不同尺寸的牆壁參數，驗證系統能正確計算出覆蓋路徑。

**Acceptance Scenarios**:

1. **Given** 操作員輸入牆壁寬度 3m、高度 2.5m, **When** 系統計算路徑, **Then** 產生的路徑覆蓋完整的 3m x 2.5m 區域
2. **Given** 牆壁尺寸在機械手臂單次可覆蓋範圍內, **When** 系統規劃路徑, **Then** 四輪車不需要平移，僅靠機械手臂完成噴漆

---

### User Story 3 - 模擬環境中驗證路徑 (Priority: P3)

在執行實際噴漆之前，操作員可以在模擬環境中預覽機械手臂和四輪車的運動路徑，確認無碰撞且覆蓋完整後再執行。

**Why this priority**: 模擬預覽能避免實際執行時的碰撞或漏噴，降低試錯成本。

**Independent Test**: 在模擬環境中載入牆壁模型，執行路徑規劃並視覺化確認軌跡正確。

**Acceptance Scenarios**:

1. **Given** 路徑已規劃完成, **When** 操作員在模擬環境中預覽, **Then** 可以看到機械手臂和四輪車的完整運動軌跡
2. **Given** 模擬中發現碰撞風險, **When** 系統偵測到碰撞, **Then** 標示碰撞位置並提醒操作員調整

---

### Edge Cases

- 牆壁尺寸超過四輪車+機械手臂最大覆蓋範圍時，系統如何提示操作員？
- 機械手臂在接近運動極限（joint limits）時，如何確保路徑仍然可行？
- 四輪車平移過程中若定位不精確，對噴漆覆蓋率的影響如何處理？
- 牆壁前方有障礙物（如管線、突出物）時，Phase 1 是否需要處理？（假設 Phase 1 僅處理平整無障礙牆面）

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系統 MUST 能根據給定的牆壁寬度和高度，自動產生覆蓋整面牆壁的掃描式路徑
- **FR-002**: 系統 MUST 將路徑分解為「機械手臂垂直掃描」和「四輪車水平平移」兩個協調動作
- **FR-003**: 機械手臂 MUST 能在垂直方向上產生均勻的掃描軌跡（上下來回），確保噴漆厚度一致
- **FR-004**: 四輪車 MUST 能在水平方向上精確平移固定距離，對齊下一個噴漆條帶
- **FR-005**: 系統 MUST 確保相鄰噴漆條帶之間有適當的重疊量，避免出現漏噴縫隙
- **FR-006**: 系統 MUST 在路徑規劃時檢查機械手臂的關節限制，確保所有路徑點都在可達範圍內
- **FR-007**: 系統 MUST 支援在模擬環境中視覺化顯示規劃的路徑
- **FR-008**: 系統 MUST 在牆壁尺寸超出最大覆蓋範圍時向操作員發出警告（基於 Universal Robots UR5/UR10 的工作範圍，UR10 約 1.3m）

### Key Entities

- **牆面 (Wall Surface)**: 待噴漆的目標平面，由寬度和高度定義，Phase 1 假設為無深度的平整表面
- **噴漆條帶 (Paint Strip)**: 機械手臂一次垂直掃描所覆蓋的區域，由噴嘴寬度和手臂可達範圍決定
- **掃描路徑 (Scan Path)**: 機械手臂在單一條帶內的上下運動軌跡
- **平移路徑 (Shift Path)**: 四輪車在條帶之間的水平移動軌跡
- **任務 (Paint Task)**: 一次完整的噴漆工作，包含所有條帶的掃描路徑和平移路徑的組合

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 對於 3m x 2.5m 的標準牆面，系統能在 10 秒內完成路徑規劃
- **SC-002**: 規劃路徑的牆面覆蓋率達到 95% 以上
- **SC-003**: 相鄰噴漆條帶的重疊率控制在噴嘴寬度的 10%-20% 之間，確保無漏噴且不過度重疊
- **SC-004**: 所有規劃路徑點均在機械手臂可達範圍內，碰撞檢測通過率 100%
- **SC-005**: 操作員能在模擬環境中完整預覽路徑並在 5 分鐘內確認或調整任務參數

## Assumptions

- Phase 1 僅處理無深度的平整牆壁，不考慮凹凸面或障礙物
- 四輪車的移動為簡單的左右平移（1D），不涉及前後移動或旋轉
- 噴漆為單一顏色，無須換色或分區上色
- 四輪車與牆壁之間的距離在任務開始前已由操作員手動調整到適當位置
- 機械手臂採用 Universal Robots 系列（UR5/UR10），UR10 工作半徑約 1.3m
- 機械手臂的末端執行器（噴嘴）已安裝且校準完成
- 使用 ROS2 Jazzy + MoveIt2 作為機器人控制框架
- 開發初期以模擬環境為主，實體硬體整合為後續工作
